# 🛡 Sentinel Antivirus

Учебный симулятор современного антивирусного сканера. Написан на чистом
HTML, CSS и JavaScript — без фреймворков и библиотек.

Это **не настоящий антивирус**: для реальной проверки файлов на угрозы
нужен низкоуровневый доступ к системе (драйверы, доступ к файловой системе
ОС). Sentinel показывает, как может выглядеть и работать интерфейс и
логика такого продукта, используя эвристику по расширению и имени файла —
полностью в браузере, без отправки файлов куда-либо.

## Возможности

- 📁 Drag & Drop и выбор файла через диалог
- 📊 Реалистичная симуляция сканирования: прогресс-бар, стадии проверки, лог в реальном времени
- 🔍 Эвристический анализ:
  - опасные расширения — `.exe .bat .cmd .vbs .scr .ps1 .js`
  - подозрительные слова в имени файла — `crack keygen hack virus trojan ransom`
  - оценка риска 0–100 и вердикт `Safe / Suspicious / Dangerous`
- 🕓 История сканирований (сохраняется в `localStorage`)
- 🌗 Светлая и тёмная тема (с запоминанием выбора)
- 📈 Статистика: всего файлов, проверено, опасных, безопасных
- ♿ Доступность: фокус с клавиатуры, `prefers-reduced-motion`

## Как это работает

Файл никогда не читается и не отправляется никуда — используются только
его **имя**, **расширение** и **размер** (для правдоподобной длительности
сканирования). На основе списков `DANGEROUS_EXTENSIONS` и
`SUSPICIOUS_KEYWORDS` в `js/scanner.js` начисляются баллы риска:

| Условие                              | Баллы |
|---------------------------------------|-------|
| Опасное расширение                    | +50   |
| Каждое подозрительное слово в имени    | +30   |

- `0` баллов → **Safe**
- `1–49` баллов → **Suspicious**
- `50+` баллов → **Dangerous**

## Структура проекта

```
Sentinel-Antivirus/
├── index.html
├── css/
│   ├── style.css        — токены дизайна, layout, компоненты
│   └── animations.css   — скан-линия, пульсации, анимации появления
├── js/
│   ├── storage.js        — localStorage: история, статистика, тема
│   ├── scanner.js         — эвристика и симуляция сканирования
│   ├── ui.js              — рендеринг интерфейса
│   └── app.js             — обработчики событий, очередь файлов
├── assets/icons/
│   └── shield.svg
└── README.md
```

## Стек

HTML · CSS (custom properties, Grid) · JavaScript (без сборщиков и
библиотек) · localStorage

## Запуск

Открыть `index.html` в браузере — сборка и сервер не требуются.
